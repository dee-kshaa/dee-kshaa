## ◈ About

Pre-final year Electronics and Communication Engineering student at CMRIT Bengaluru (VTU), with two IEEE-accepted research papers and a completed internship at the Airports Authority of India's GAGAN Complex — one of only four operational SBAS systems globally. My work sits at the junction of signal processing, satellite navigation, and applied AI.

I build systems end-to-end: from real-time GNSS satellite performance monitoring and Python automation on live AAI infrastructure, to production AI pipelines (FastAPI, vision-language models, XAI), to full-stack web platforms. Research outcomes get shipped as working code; hardware constraints inform software design.

As Vice Chairperson of the IEEE Signal Processing Society Student Chapter at CMRIT, I work under Dr. Abhishek Appaji (IEEE SPS Bangalore Chapter Founding Chair) on chapter-level technical initiatives, ideathon coordination, and IEEE SPS scholarship programs.

**Open to:** Graduate research positions (MS/PhD) in Signal Processing, Satellite Systems, or Biomedical AI · Research Internships · IEEE technical collaborations

## ◈ Featured Projects

<details>
<summary><strong>SafeIntern-AI — AI-Powered Internship Fraud Detection Platform</strong></summary>

An end-to-end production pipeline that detects fake internships, scam certification programs, and fraudulent recruiter messages. Combines a fine-tuned Gemma LLM, OCR-based document ingestion, and post-hoc XAI (LIME + SHAP) into a single FastAPI service with a React frontend.

| Attribute | Detail |
|-----------|--------|
| **Stack** | Python · FastAPI · Gemma LLM · LIME · SHAP · OCR · React · JavaScript |
| **Architecture** | Six-stage classification pipeline: ingestion → OCR → LLM inference → XAI → scoring → verdict |
| **XAI Layer** | LIME and SHAP provide per-prediction explanations on text and tabular features |
| **Security** | Pydantic v2 validation throughout; no raw SQL; structured error handling |
| **Impact** | Primary research differentiator — demonstrates production-grade AI engineering with explainability |
| **Repository** | [dee-kshaa/SafeIntern-AI](https://github.com/dee-kshaa/SafeIntern-AI) |

Post-hoc explainability is the differentiating layer here — most student AI projects skip it entirely. Honest scope note: current XAI covers text/tabular features, not CNN image explainability.

</details>

| Attribute | Detail |

| **Signal Capture** | Multi-operator RSSI comparison via SIM7600 cellular module |

| **Visualization** | Real-time Python dashboard for live signal strength comparison |
| **Team** | Deekshaa Balachandran · Harsha B L · Jalli Haneesha · Mithil R Kokane |

Hardware-software co-design with real telecom data. The FreeRTOS multitasking layer differentiates this from typical Arduino projects.

</details>

## ◈ Experience

**Graduate Intern — GAGAN Complex, Airports Authority of India**
*GNSS / SBAS Division · Bengaluru, India · 2024*

GAGAN (GPS-Aided GEO Augmented Navigation) is one of four operational Satellite-Based Augmentation Systems (SBAS) globally — alongside WAAS (USA), EGNOS (EU), and MSAS (Japan). Worked on live AAI satellite navigation infrastructure.

- Real-time satellite signal performance monitoring across GAGAN's ground station network
- Python automation scripts for processing and visualizing live GNSS/SBAS telemetry data
- Analysis of ionospheric corrections, satellite geometry metrics, and integrity parameters
- Contributed to operational documentation for SBAS performance evaluation

`Python` `GNSS` `SBAS` `Signal Processing` `Satellite Navigation` `Data Automation`
